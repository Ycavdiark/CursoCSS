¿Qué es CSS?

CSS es un lenguaje de hojas de estilo que permite controlar la apariencia de los documentos HTML.

Gracias a CSS podemos cambiar colores, tamaños, espacios, bordes y la distribución de los elementos.

Propiedades importantes de CSS

01

Colores

Permiten cambiar el color del texto y del fondo.

color: purple;
02

Tipografía

Modifica el tamaño y el tipo de letra.

font-size: 18px;
03

Espaciado

Controla la separación entre los elementos.

margin: 15px;
04

Diseño

Organiza los elementos en filas o columnas.

display: flex;

¿Cómo funciona CSS?

1

HTML crea la estructura

Define títulos, párrafos, imágenes y enlaces.

2

CSS aplica los estilos

Indica los colores, tamaños y posiciones.

3

El navegador muestra el resultado

Combina la estructura y los estilos para mostrar la página.

¡Ahora sabes lo básico!

HTML construye la estructura y CSS le da personalidad. Juntos permiten crear sitios web atractivos y organizados.
